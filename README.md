## 📖 Book Manager REST API

A professional REST API project built using **Node.js** and **Express.js** to perform CRUD (Create, Read, Update, Delete) operations on a collection of books. The application stores data in memory and includes a clean, responsive frontend for interacting with the API through a user-friendly interface.

This project demonstrates the fundamentals of **RESTful APIs**, **Express Routing**, **HTTP Methods**, **JSON Handling**, and **Client–Server Communication**.

---

## 🚀 Features

- 📚 View all books
- ➕ Add a new book
- ✏️ Update existing books
- 🗑️ Delete books
- 🔄 RESTful CRUD operations
- ⚡ Express.js backend
- 🌐 Responsive frontend
- 📦 In-memory data storage (No Database)
- 📡 JSON request & response handling
- 🧪 API tested using Postman

## 📡 REST API Endpoints

| Method | Endpoint | Description |
|---------|----------|-------------|
| GET | `/books` | Retrieve all books |
| POST | `/books` | Add a new book |
| PUT | `/books/:id` | Update a book by ID |
| DELETE | `/books/:id` | Delete a book by ID |

## ▶️ Getting Started

### Clone the Repository

```bash
git clone https://github.com/Lokesh-Soft-Dev/Task-3-Book-REST-API.git
```

### Navigate to the Project

```bash
cd Task-3-Book-REST-API
```

### Install Dependencies

```bash

```

### Start the Server

```bash
npm start
```

### Open in Browser

```

```
